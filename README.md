# arnel-post-assets

Public image assets for Arnel Bukva's LinkedIn and X posts.

**Why this repo exists.** Buffer does not host images. It fetches the image URL at the moment
it publishes, so any link that expires — a Notion file URL expires in one hour — is a dead link
by the time the post sends. On 2026-08-26 a post went out with no visual because of exactly that.

Files here get a permanent, public raw URL that Buffer can always read:

```
https://raw.githubusercontent.com/ArnelBukva/arnel-post-assets/main/<path>
```

Layout: `YYYY/MM/YYYY-MM-DD-slug.png`.

Everything in here is intended for public publication anyway. Nothing private goes in this repo.
